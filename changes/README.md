# Change fragments

One file per build stream (`changes/<stream>.md`: `spine`, `fe1`, `sv1` … `sv7`, `fe2` …).
Each agent records here what it kept / adapted / rewrote / dropped, deviations from the mockup,
`TODO(decision)` items and anything the owner must configure. The fragments are merged into the
root `CHANGES.md` at the end of each phase.
